# Interface language acceptance

Product: `e9c44e0e6af25781e5065d0db04b83ed1ffc2a08`.
Fixture: `d7854cf49c30c557e142b0503ec17d4c6d485a50`.

The source-host job in [build run 44010709664](https://github.com/xiongnemo/nemoterm/actions/runs/44010709664)
succeeded. Its original UI fixture incorrectly tried to select a different
process's HFONT for measurement and reported false text clipping. The corrected
fixture clones the font description into its own process, checks GDI failures,
and replays the identical executable. No production files changed for replay.

[Final acceptance run 44011877414](https://github.com/xiongnemo/nemoterm/actions/runs/44011877414)
passed on a disposable GitHub-hosted `windows-2025` runner with `en-US` display
language. Evidence is archived in [i18n-ci-e9c44e0.zip](i18n-ci-e9c44e0.zip),
including the source manifest, full logs, original-size PNGs and JSON checks.

Interaction checks cover invalid stored values, follow-system selection, CLI
override without persistence, Cancel, pending selection across page changes,
Save, restart-only application, shared preference across profiles, switching
back to English, translated menus, Chinese profile names through Save/restart,
and option-looking arguments after `-e` reaching the child unchanged.

Visual inspection covered Chinese language settings at 100%, character encoding
at 200%, and a Chinese-named profile. An earlier screenshot review caught a real
bug: the static controls still used `SS_LEFTNOWORDWRAP` even though the layout
reserved multiple lines. The product now uses wrapping static controls, and the
final fixture checks text extent using the actual control style and font.

Nine GDI startup samples on this runner measured **3.63–3.86 MiB private working
set** and **28.60–29.26 MiB total working set** without trimming. These are light
startup observations, not a replacement for dense-scrollback memory acceptance.

This was targeted UI/build acceptance, not the full protocol/sanitizer suite.
Mixed-DPI multiple monitors, physical GPU drivers, real IME candidate windows,
and nested Windows common-dialog layouts were not certified. Some inherited
colour names, font descriptions and diagnostics remain English. Windows-owned
dialog text follows the Windows language; licence text stays original.

Use **Window / Interface language**, select **简体中文**, click **Save and Apply**
(or **Save and Open** in startup settings), then restart. The Chinese location is
**窗口 / 界面语言**. See [language support](../docs/I18N.md) for persistence and CLI
details. No local desktop UI tests were run for this change.
