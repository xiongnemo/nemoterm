# OSC 50: scalable font families

In Windows, **Window → Appearance → Font access** controls whether the application can query and change its terminal's font family. Both permissions default to off. This is separate from user zoom. A successful application request changes the active face and refreshes glyph and graphics caches for that view, without editing the profile. An unavailable family is ignored instead of silently selecting GDI's substitute. Revoking write access discards an existing override. The X11 bitmap font database and its XLFD patterns are not available on Windows.
