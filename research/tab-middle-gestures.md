# 中键松手时应该关闭哪个标签？

在 A 标签按下中键，拖到 B 才松手，旧版 Nemoterm 会误关 B。如果按住中键期间 A 自行退出，B 移到原位置，松手甚至会关闭整个窗口。修复让宿主记住按下时的标签；只有松手仍在该标签上才会请求关闭。移动到其他标签、收到 Windows 取消消息，或者原标签已退出，都会取消本次关闭。中键点击加号也不会打开新标签。

| 真实鼠标手势 | 旧单文件 10f0390f | 修复后 a96e10b4 |
| --- | --- | --- |
| 在未激活的 A 上按下并松开 | 四个方向均只关闭 A | 四个方向均只关闭 A |
| 在 A 按下，到当前标签 B 松开 | 四次都误关 B | A、B 都保留 |
| 中键点击加号 | 四次都意外新建了第三个标签 | A、B 都保留 |
| 按下后取消，再在 A 处松开 | 四次都误关 A | A、B 都保留 |
| 按住期间 A 自行退出，松手时 B 移到原位置 | 四次都关闭了剩余窗口 | B 保持激活 |

[旧 EXE 的远程桌面回放](https://github.com/xiongnemo/nemoterm/actions/runs/44661411567)和[新 EXE 的完整 CI](https://github.com/xiongnemo/nemoterm/actions/runs/44661690615)使用同一支 Windows 输入脚本，每项开一个新窗口，两次提交的实际测试脚本相同。通过时 B 同时收到按下期间键入的 3 和松手后键入的 4。上下左右各自还核对了悬停预览实时变色、焦点、应用收到的按键和 Shift+左键选区的 Ctrl+Shift+C 剪贴板文本。两版都保留原始窗口记录和截图。
