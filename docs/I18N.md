# 界面语言

设置入口是 **Window → Interface language**；中文界面中为 **窗口 → 界面语言**。支持跟随 Windows 显示语言、English、简体中文。选择后点击 **Save and Apply / 保存并应用**（启动设置为 Save and Open / 保存并打开），关闭并重新启动 Nemoterm 后生效。Cancel / 取消不保存语言选择，已打开的窗口保持原语言。

这是全局偏好，不随 profile 切换。保存位置为 `HKCU\Software\Nemo\Nemoterm` 的 `UILanguage`，值为 `system`、`en` 或 `zh-CN`；缺省及无效值使用 `system`。保存失败会显示 Windows 错误码，设置窗口保持打开。profile 页单独的 Add / Save 操作只保存 profile；语言在关闭设置时通过 Save and Apply / Save and Open 提交。

临时覆盖：

```powershell
.\nemoterm.exe --ui-language zh-CN
.\nemoterm.exe --ui-language en
.\nemoterm.exe --ui-language system
```

覆盖只用于本次启动，不写注册表。`-e` 之后的参数属于子进程。跟随系统使用 `GetUserPreferredUILanguages` 的有序显示语言列表，识别英语及 `zh-CN`、`zh-SG`、`zh-Hans`；不把繁体中文冒充简体，未匹配时回退英语。键盘布局、输入法及日期区域不决定界面语言。

## 翻译范围

目前词表为 427 条配对文案，接入主要设置页面、分类树、终端菜单、profile 提示、响铃、快捷键、标签页、字符编码、渲染和界面语言设置。技术标识和键名保留英文。少量继承的详细颜色名称、字体描述、诊断和错误分支仍保留英文；这不是全部 PuTTY 工具的完整中文本地化。Windows 文件、颜色、字体选择器的系统文案跟随 Windows，许可证保留原文。

界面语言不会改变终端字符编码、shell 输出、应用输出、用户填写的 profile 名称、路径或自动化协议。原来的 **Window / Translation** 是字符编码页，中文名称是“字符编码”；不是界面语言入口。Default 身份及已有注册表键保持兼容。

## 实现与维护

- `locales/en.json` 和 `locales/zh-CN.json` 使用语义 ID。`scripts/generate-ui-catalog.py` 校验重复键、对应键集合及命名参数后生成只读 C 表，编译到单个 EXE 中；运行时不加载语言包，不增加 DLL 或字体文件。
- 修改词表后运行 `python scripts/generate-ui-catalog.py`，同时提交生成的 `vendor/putty-0.85/utils/nemo_ui_catalog.h`。构建脚本用 `--check` 拒绝过期的生成物。
- `nemo_ui_text(id)` 查表，空中文条目回退英文。`nemo_ui_format` 只做一次命名参数替换，用户内容不递归展开，也不作为 printf 格式串。
- 控件和菜单在 Win32 边界转 UTF-16。设置标题、分类树、列表、编辑框、提示和换行使用 Unicode 接口。分类路径、命令 ID 和配置键不翻译；快捷字母使用已有元数据。
- 不热重建当前进程的窗口。新进程读取保存值；CLI 覆盖不改变设置页显示的全局已保存选择。

## 验证

本地只做编译、词表和核心函数测试。远程 GitHub Actions 使用最终单 EXE，在英文 Windows 上运行 `tests/i18n_window_smoke.py`：检查中文标题、临时覆盖、取消、跨页面保留选择、保存、重启、跨 profile 使用和切回英文，结束后恢复全局偏好。

首轮接入已通过[远程验收](../research/i18n.md)：24 个场景、440 次页面检查、2,508 个控件检查及 8 项语言交互检查。截图确认长句正确换行；记录包含成品哈希、真实 DPI 和覆盖限制。

[DPI workflow](../.github/workflows/dpi.yml) 对中英文各检查 standalone / tabs、100/125/150/175/200% 实际系统缩放、运行中缩放及 10 个设置页面，上传 UI Automation 几何数据和截图。实际 DPI 由 Windows 查询，模拟消息测试另行记录。混合 DPI 双屏及真实用户显卡驱动仍未覆盖。最新实测结论见仓库中的验收记录；词表键数或脚本存在本身不表示测试已经通过。
